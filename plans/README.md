# Retained renderer: port overview

The target is what an application can do on Emerge `main`
(`aef5e42fc789c396505f85c34810b2ca9c008586`). On the retained renderer an app can
mount a viewport, draw and update a tree, and navigate or manipulate what was actually submitted.
It **cannot** yet run the full `main` UI or renderer API. The
[API parity tracker](api-parity.md) lists the remaining work. [Scroll clipping and automatic paint virtualization](scroll-paint-visibility.md) keeps the full layout but prepares only candidate rows for draw and hit packing. The [static Size qualification](size.md) covers document blocks and floats, height shares through nested containers, Row wrap charges and retained-only column packs. It supersedes the [special Row scheduler](row-independent-turn.md#result) while retaining its geometry controls. The [transform](static-layout-transforms.md) and [Image](image-sizing-and-codecs.md) checkpoints cover rotated slots, installed inverse hits, aspect and still codecs.

| What works now | Boundary |
| --- | --- |
| `use Emerge`: mount, render, rerender, configure, receive raw input and route clicks; direct renderer startup, status, capture and shutdown | Ordinary binary headless and explicit Wayland sessions. Input uses the **last successfully submitted frame**, not the last accepted tree. |
| **9 of 13** `main` element kinds: `el`, `text`, `none`, `row`, `column`, `wrapped_row`, `paragraph`, `text_column`, `image` (including `svg/2`); **one addition: `wrapped_column`** | [Paragraphs](checkpoints/layout/paragraph.md) wrap direct Text and El→Text, align each line, and paint and hit-test styled continuations. [TextColumn](checkpoints/layout/text-column.md) carries side floats across paragraphs and clears them before ordinary blocks. Standalone Text is single-line and [aligns ink inside its offered box](../test/emerge_skia/text_alignment_test.exs). Bundled sans/mono faces work; custom fonts and editors are separate. [PNGs](checkpoints/layout/raster-images.md) and [JPEGs](checkpoints/layout/jpeg.md) support intrinsic/aspect sizing, contain/cover and static image or enclosing El opacity. JPEG sizing follows EXIF display orientation. [Fitted decode](checkpoints/layout/sized-rasters.md) grows the retained bitmap on demand and reuses it for smaller draws. [SVG leaves](../guides/tutorials/use_assets.md#tint-an-svg) share a vector picture across sizes, including when an authorized file and inline bytes contain the same art. [Image paint rotation/scale, GIF frame zero and file backgrounds](images-and-svg.md) also work. [Bounded Image lengths and height-driven widths](image-sizing-and-codecs.md) use an independent height or a placement-only width. Raster workers decode Windows `BI_RGB` BMP (1/4/8/24 bpp) and still WebP; neither requires runtime conversion. `Input.button/2` builds an `el`. |
| Static widths/heights and linear layout | The viewport offers both axes without moving an [aligned root](../test/emerge_skia/root_alignment_test.exs) away from `(0,0)`. A [direct child of El](../test/emerge_skia/el_child_alignment_test.exs) can override the host's alignment on either axis. Row and Column share the main axis; wrapped forms share it **per group**. [Start, center and end groups](../test/emerge_skia/linear_zones_test.exs) use each settled line or column without reordering paint or clicks. All four layouts can [distribute even gaps](../test/emerge_skia/linear_even_spacing_test.exs) within each group on a pixel or fill-bearing main axis. Authored spacing still decides wrap breaks. [El, Text and None ignore the even-spacing flag](../test/emerge_skia/inactive_even_spacing_test.exs). Cross-axis alignment uses the padded host or each wrapped group. Static lengths can combine pixels, content and multiple fills. A WrappedColumn can fit the occupied widths and gaps after grouping its children; it cannot use a share that depends on [that very packed width](size.md#s7-real-feedback-and-the-closing-audit). |
| [Nearby panels](nearby-layers.md) | All six slots use the host's local border box without taking ordinary layout space. Sibling menus share a layer; their tooltips sit above both, below an ancestor's overlay. [Layout after host placement](nearby-layout-scheduling.md) gives packed columns, height-sized images and reflowed paragraphs their final slot offers. An inline `el` anchors one panel per declaration across all its aligned lines. A panel on a scrolling row stops at the port. Only a port-owned panel can escape it; set `clip_nearby()` to clip that panel too. |
| [Scrolling](scrolling.md) and [other scroll inputs](other-scroll-inputs.md) | Scroll a bounded container by wheel, track/thumb, mouse or touch pan, arrows, page or endpoint keys. Tab can reveal an offscreen stop through nested ports without making it a pointer target. Direct touch can coast after release. Fraction bindings, keyed jumps and echo protection use the same controller. Editor scrolling is separate. |
| Layout rotation vs transforms that preserve sibling layout | `UI.rotate/1` reserves and draws a turned block or float. On a [paragraph span](inline-layout-rotation.md), it turns the phrase and its click target and reserves the rotated footprint on the line, so following text can move or wrap. `Transform.rotate/1` turns the ink and hit regions without changing sibling layout. [Local clicks](../test/emerge_skia/static_transforms_test.exs) follow the installed shape and clips; opacity alone doesn't move or disable a target. No animation clock. |
| **10 of 19** element `on_*` listeners: click, scroll, press, focus, blur, drag and four directional swipes | Click and drag use element-local coordinates; a swipe supplies local endpoints and elapsed milliseconds. Scroll sends fractions. Focus, blur and press deliver the stored message unchanged. Raw key/touch subscriptions are independent. No general hover or custom key listeners. |
| **3 of 6** binary headless pixel formats: RGBA8888, BGRA8888, RGB888 | CPU-delivered `VideoInterop.Frame` and installed-frame RGB/RGBA or PNG capture. Producing a binary frame is not video import or PRIME export. |
| [Renderer diagnostics](retained-renderer-stats.md) | `logs: [:stats]` logs five-second windows of tree, draw, handoff and input timings on binary headless and Wayland. Includes idle windows without a redraw. `stats: true` alone collects silently. |
| Wayland CPU (`wl_shm`), OpenGL and Vulkan | Compositor pixels and seat input on all three. An isolated seat checked installed coordinates across a 1.0→1.5 configure on shm and AMD hardware GL/Vulkan. Vulkan synchronization controls ran there; broader hardware coverage and physical scanout remain unverified. |

These counts have different denominators. There is no meaningful overall API
percentage: a color constructor, a listener and a display backend are not equal
units of work. The ordinary Mix suite is not green. See the [input qualification](other-scroll-inputs.md#verification) for the seed-17 failures compared by name with [renderer diagnostics](retained-renderer-stats.md). These counts are not a port score.

## How we work

The [live tree isolation checkpoint](checkpoints/performance/tree-owner-isolation.md) compares accepted edits, installed frames and input during a stalled handoff. It also records the higher cost of unstalled edits.

The [snapshot reconciliation work](reconciliation-and-diffing.md) changes producer bookkeeping, not the viewport API. Its [checkpoint](checkpoints/performance/snapshot-diff.md) separates diff time, allocation and delivered frames.

Select **one observable behavior** from the tracker. Record its `main` reference,
expected result and how to observe it. After it is delivered, update the coverage
above, retire that item, and remove its plan. Do not queue several active ports
or keep finished plans here.

Keep the [decision record](../guides/internals/retained-decisions.md) when the
implementation route **or** behavior differs from `main`. Put user-visible deltas
in [changelog candidates](../guides/internals/retained-changelog-candidates.md),
including intentional changes as such. Those two records outlive any plan.
