**Complete for logical `.png` sources in `Emerge.UI.image/2`.** Pinned `main`: `aef5e42fc789c396505f85c34810b2ca9c008586`. Before this port, `3e964e7` refused the same public upload: `renderer_upload failed: unsupported element 9 in first slice`. Each producer was paired with its own verified mapped NIF. No new public API, opcode or wire fields.

## Resource and layout contract

- `~m` and logical strings resolve from one renderer's application `priv/` directory. The [loader](../../../native/emerge_skia/src/raster_assets.rs) uses a directory handle, refuses symlink descendants and checks file type, bytes and dimensions before allocating decoded pixels. Limits are 64 MiB each for the encoded file and decoded bitmap, 32,768 per axis and 256 MiB resident decoded pixels per loader; these are not total process or GPU memory limits. Entry/byte cache limits may both be zero. Live and sealed bitmap references survive eviction.
- A [worker](../../../native/emerge_skia/src/session/images.rs) starts only when needed. Filesystem and codec work run outside the session lock and draw replay. An occurrence ticket can settle only its still-current binding; a successful completion requests a frame, **not** an input installation. Keep the old pixels and dimensions together while loading a replacement. An unknown size has a 64×64 content fallback and no ratio; valid missing/corrupt files settle to a failure indicator. Invalid declarations refuse atomically. One-shot snapshot and await use the same tree.
- The [image leaf](../../../native/emerge_skia/src/tree/shapes/image.rs) measures intrinsic device texels. An explicit pixel axis projects the opposite content size inside padding/border; fill width projects auto height from the settled inner width in Reflow. A fixed box centers its contain destination or cover crop. No speculative width from a future height share. Equal-size pixel replacement and opacity changes need no layout. Sampling bleed changes neither layout nor hit bounds.
- [Prepared drawing](../../../native/emerge_skia/src/tree/paint/opacity.rs) applies static Image/El opacity to one ready bitmap's paint, including already-flattened pixels. Multiple draws compose once into a bounded layer. Alpha one needs no opacity layer; zero skips paint, not hit collection. This is not a paint-layer cache or a frame-time result. See [D16](../../../guides/internals/retained-decisions.md#d16-apply-image-opacity-at-the-compositing-boundary).

## What was observed

- The [200×100 red PNG](../../../priv/test_assets/single_axis_wide.png), fill-width in an unpadded Column, moved the following sibling to **y=40 → 150 → 40** at widths **80 → 300 → 80**. All three complete 320×180 submissions matched `main`. A direct host may bleed to x=80 at width 80; an outer Column's strict clip still applies. The [edit/undo regression](../../../test/emerge_skia/raster_images_test.exs) changes that outer clip at constant image width.
- **220/228** complete 90×80 raster frames matched pinned `main` exactly (19 cases × two authored scales × opacity 0/0.5/1 × two backdrops, `decode_at_size: false`). All opacity-zero and opacity-one controls matched. The other eight had **57 differing pixels in total, maximum one level per channel**, only at rounded or clipped edges at half opacity. Applying the rectangular clip *before* the rounded mask mattered even at alpha one. With only direct bitmap folding disabled and isolation forced unbounded, the same candidate matched **228/228**: the remaining difference is the intermediate 8-bit quantization, not a different fit, source or missing group. Each arm's **229 fresh mounts and 456 patches/undos** matched its own one-shot buffers, including contain/cover, insets, decoration, shadows, nested opacity and failure.
- A separate 18-frame host control had nine exact matches, one half-opacity rounded-edge difference and eight overflow differences. `main` clipped the image to an undersized plain El; retained preserves the [ordinary El overflow rule](../../../guides/internals/retained-decisions.md#d6-resolve-constraints-at-the-site-that-offers-the-space). Applying only each reference host's rectangle to the retained buffers reproduced all eight exactly. This is separate from alpha rounding.
- [Replay counters](../../../native/emerge_skia/src/tree/paint/opacity/tests.rs): one image draw, zero opacity layers for both a sampled PNG and a flattened snapshot. A half-alpha texel at half opacity had alpha 64. Two overlapping opaque fills at half opacity used **one** explicit `(7,6)–(35,19)` layer hint on a 160×120 surface, with alpha 128, not 192, in the overlap. The bounds include paint outsets and are clipped and rounded in device space, then mapped back to canvas coordinates. No inference about the storage Skia actually allocated.
- Each arm passed **six complete private Sway crops and 18 real button events** on raster/CPU. Raw press/release reached `handle_input/2`; `handle_info/2` received sibling-local `(4,3)` at surface `(4,43) → (4,153) → (4,43)`. Image-local `(4,3)` still clicked the image under direct zero, enclosing zero and enclosing half opacity. Both windows closed normally. [Native controls](../../../native/emerge_skia/src/tree/tests/images.rs) separately verify rejection, stale/detached completions and sealed-B/accepted-C submission success/failure.
